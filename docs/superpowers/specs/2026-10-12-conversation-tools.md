# Hotel conversation tool engine

User-authorized goal: understand the whole WhatsApp turn, carry context and readable language/script, execute verified hotel tools, then answer every question using actual results. Preserve billing, stay/ID permissions, cart confirmation, deduplication, staff routing and notifications. No demo activation, guessed delivery estimates or provider change.

A dedicated engine plans an array of up to four independent operations and all conversational questions. It receives sender-owned state, recent role-separated dialogue and hotel facts. Validate the complete plan before any action. Independently review each operation using the existing transaction reviewer and sender state. Never allow cart creation and confirmation in one turn. Existing executors remain canonical adapters; their text results are collected per turn, staff transport remains real. AI writes one complete guest response from the collected results and verified facts; an independent support/coverage check rejects unsupported claims. Protected numbers, links and data rows remain exact. Script preference belongs to AI planning, with Roman-script output validated.

Failure: invalid planning or review means no actions; executor errors stop the remaining operations and disclose uncertain outcomes without retrying writes; final AI failure sends verified collected results and admits inability to answer remaining questions. Never replay a transaction because wording failed. Image dispatch remains a real tool with actual result. Preserve the outer durable webhook, transport and conversation recording.

Verification: multi-intent order/time, order plus service, readability correction with no menu tool, neutral confirmation preserving script, invalid plans, guessed quantities, same-turn confirmation, tool failure after write, unsupported final replies, exact result data and isolation between guest/staff/turns. Full existing regression suite before publishing. Live provider/WhatsApp checks are distinct from offline tests and must be reported separately.
